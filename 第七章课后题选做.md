1.编写一个程序，读取整数直到用户输入 0。输入结束后，程序应报告用户输入的偶数（不包括 0）个数、这些偶数的平均值、输入的奇数个数及其奇数的平均值。（编程练习第三题）
```c
#include<stdio.h>
int main(){
    int a;
    int cnt1=0,cnt2=0;
    double sum1=0,sum2=0;

    while(scanf("%d",&a)==1&&a!=0){
        if(a%2==0){
            cnt1++;
            sum1+=a;
        }
        else{
            cnt2++;
            sum2+=a;
        }
    }
    printf("偶数个数%d、偶数的平均值%f",cnt1,sum1/cnt1*1.0);
    printf("输入的奇数个数%d,其奇数的平均值%f",cnt2,sum2/cnt2*1.0);

    return 0;
}
```
